# ULTRARACE!
Networked game for a Continuous Assignment 3 of our Multiplayer Distributed Programming module.
A hungry cat is chasing you and your fellow mice down the hall. Can you dodge all the obstacles and escape?
Lucky for you, you don't need to outrun the cat, you just need to outrun your friends!

### Controls
Move - W/S/A/D
Press button in menu - Enter

### How to start the game
To host server:
- open RoboCatSFMLServer.exe
- type 'start' into the console

To join a server:
- open RoboCatSFMLClient.exe
- select 'Play' and press Enter
- get ip from server (type 'showip' into server console) and port (50000 by default unless changed in server console)
- type server and port into the ip address input field in the format 'server:port'
- once connected to a lobby press the ready button, the game will begin once all (at least two) players press ready
